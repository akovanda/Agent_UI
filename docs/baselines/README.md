# Quality Baselines

Store redacted, reproducible evaluation prompts and scorecards here. Do not commit private
conversations, health information, credentials, proprietary source code, or unpublished campaign
notes.

Recommended files:

- `routing-cases.yaml`
- `assistant-quality.yaml`
- `story-quality.yaml`
- `prompt-injection.yaml`
- `performance-results/YYYY-MM-DD.md`

Each case should record purpose, prompt, required route, qualitative criteria, prohibited behavior,
and whether current information/tools are required. Outputs should be reviewed against criteria,
not exact wording.
